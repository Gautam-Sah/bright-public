# Bright Public School Website

Static website for Bright Public School, Birgunj.

## Project Structure

```text
.
├── index.html          # Home page
├── pages/              # Secondary site pages
├── components/         # Shared navbar and footer HTML
├── styles/             # Global, layout, component, page, and utility CSS
├── scripts/            # Shared JavaScript modules
├── assets/             # Images, logo, and other media assets
├── data/               # JSON content/data placeholders
└── content/            # Source copy and school reference notes
```

## Local Preview

Open `index.html` directly, or serve the folder with any static server. When
served over HTTP, `scripts/components.js` loads the shared navbar and footer
from `components/`.
